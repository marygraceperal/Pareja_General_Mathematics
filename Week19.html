SESSION 1 — Standard Normal Probabilities

Daily objectives: Identify and describe the key characteristics of a normal random variable.

ACTIVITY

Evidence gathering

Examine bell-shaped and skewed graphs. Learners identify center, symmetry, spread, and where observations cluster.

ANALYSIS

Formative check

Compare graphs and justify which characteristics support a normal model.

ABSTRACTION

Explicit modeling

Model that a normal distribution is continuous, bell-shaped, and symmetric; in an ideal normal distribution, mean = median = mode.

APPLICATION

Guided → independent

Describe several graphs and explain whether each is consistent with a normal model.

Evidence-to-action: If learners focus only on “bell-shaped,” compare normal and non-normal examples and revisit symmetry and center.

SESSION 2 — Calculating and Interpreting Z-Scores

Daily objectives: Calculate z-scores and explain positive, negative, and zero z-scores.

ACTIVITY

Evidence gathering

Compare raw scores from distributions with different means and standard deviations.

ANALYSIS

Formative check

Discuss why raw scores alone may not show relative position.

ABSTRACTION

Explicit modeling

Model z = (x − μ)/σ and interpret z = 0, positive z, and negative z.

APPLICATION

Guided → independent

Calculate and interpret z-scores in practical measurement and assessment contexts.

Evidence-to-action: If learners reverse the subtraction, use a number line and the phrase “value minus mean.”

SESSION 3 — Converting to and from the Standard Normal Variable

Daily objectives: Convert an original normal-variable value to z and recover x from a given z-score.

ACTIVITY

Evidence gathering

Match values to positions one or more standard deviations from the mean.

ANALYSIS

Formative check

Analyze errors in sign, substitution, and reverse conversion.

ABSTRACTION

Explicit modeling

Model z = (x − μ)/σ and x = μ + zσ.

APPLICATION

Guided → independent

Convert raw values to z-scores and z-scores back to original measurements.

Evidence-to-action: If learners use x = z − μ, derive x = μ + zσ from the z-score formula.

SESSION 4 — Integrated Normal Distribution Problem Solving

Daily objectives: Select the correct conversion, solve a multi-step problem, and interpret the result.

ACTIVITY

Evidence gathering

Sort prompts into “find z” and “find x,” identifying μ and σ.

ANALYSIS

Formative check

Compare solutions and locate errors involving sign or standard deviation.

ABSTRACTION

Explicit modeling

Use: identify x, μ, σ → choose direction → substitute → calculate → interpret.

APPLICATION

Guided → independent

Complete an integrated normal-variable problem independently and justify the interpretation.

Evidence-to-action: Use mastery evidence to distinguish conceptual, procedural, and interpretation errors.

LEARNER GUIDE

Normal Random Variable

Understand normal-distribution characteristics and standardization.

What You Will Learn

  • Recognize the characteristics of a normal distribution.
  • Understand mean and standard deviation as measures of center and spread.
  • Calculate z-scores.
  • Convert z-scores back to original values.
  • Interpret standardized positions.

Essential Definitions

TermMeaning
Normal random variableA continuous random variable modeled by a normal distribution.
Normal distributionA continuous, bell-shaped, symmetric probability distribution.
Mean (μ)The center of the distribution.
Standard deviation (σ)A measure of spread around the mean.
Standard normal variableA standardized normal variable with mean 0 and standard deviation 1.
z-scoreA standardized value showing how many standard deviations a value is from the mean.

Key Ideas and Formulas

  • The normal curve is symmetric and bell-shaped.
  • In an ideal normal distribution, mean = median = mode.
  • The standard normal distribution has μ = 0 and σ = 1.
z = (x − μ)/σ
x = μ + zσ
P(Z < z) = area to the left of z

Worked Examples

Example 1 — Probability below a z-value

Suppose Z is standard normal. The probability to the left of z = 1.00 is approximately 0.8413 using a standard Z-table.

Example 2 — Probability between two z-values

For −1.00 < Z < 1.00, subtract the left-tail area at −1.00 from the left-tail area at 1.00:

P(−1 < Z < 1) = 0.8413 − 0.1587 = 0.6826

Example 3 — Percentile

A learner is at the 90th percentile. The standard normal table gives a z-value of approximately 1.28. Thus the learner is about 1.28 standard deviations above the mean.

Example 4 — Find an original score

If test scores have μ = 75 and σ = 8, and the desired percentile corresponds to z = 1.28:

x = μ + zσ = 75 + (1.28)(8) = 85.24

The cut-off score is approximately 85.24.

Common Mistakes

  • Using the wrong μ or σ.
  • Reversing x − μ.
  • Thinking a negative z means a negative raw value.
  • Forgetting to multiply z by σ in reverse conversion.
  • Interpreting z as a raw score.

Real-World Connections

Normal models can support analysis of measurements, assessment results, manufacturing quality, biological measurements, and other approximately bell-shaped data.

Activity Sheet — Complete Solutions

  1. The standard normal distribution is a normal distribution with mean 0 and standard deviation 1.
  2. The area under a normal curve represents probability.
  3. The total area is 1, or 100%.
  4. The 50th percentile corresponds to z = 0.
  5. A percentile indicates the percentage of observations at or below a specified value.
  6. Use the cumulative area to the left of z.
  7. From the Z-table, P(Z < 1.00) = 0.8413.
  8. From the Z-table, P(Z < −1.00) = 0.1587.
  9. P(−1 < Z < 1) = 0.8413 − 0.1587 = 0.6826.
  10. P(Z > 1.28) = 1 − 0.8997 = 0.1003.
  11. z = (80−70)/10 = 1.00. Therefore P(X < 80) = P(Z < 1.00) = 0.8413, or 84.13%.
  12. x = μ + zσ = 75 + (1.25)(8) = 75 + 10 = 85.
  13. The table value 0.8413 is P(Z < 1.00), not P(Z > 1.00). Correctly, P(Z > 1.00) = 1 − 0.8413 = 0.1587.
  14. Because the standard normal curve is symmetric about zero, equal distances on opposite sides have equal tail areas. Thus both probabilities equal 0.1587.
  15. The 90th percentile is approximately z = 1.28. It means about 90% of observations are at or below this z-value.
  16. 1.28 is a z-score, not a probability. The probability/percentile is approximately 0.90, while 1.28 tells the standardized location.
  17. For x = 67: z = (67−75)/8 = −1. For x = 83: z = (83−75)/8 = 1. Therefore P(67 < X < 83) = 0.8413 − 0.1587 = 0.6826, or 68.26%.
  18. The 95th percentile corresponds to approximately z = 1.645. x = 75 + (1.645)(8) = 75 + 13.16 = 88.16. So approximately 95% of scores are at or below 88.16.

TEACHER NOTES

Support, Remediation and Enrichment

Common Learner Misconceptions

  • Confusing z-scores with probabilities.
  • Reading the wrong tail from the Z-table.
  • Forgetting to subtract from 1 for an upper-tail probability when using a left-cumulative table.
  • Using the wrong z-value for a percentile.
  • Failing to convert a raw value to z before using the standard-normal table.
  • Forgetting to convert a percentile probability back to a raw score.

Remediation

  • Use a labeled standard-normal curve and shade the requested region before looking at the table.
  • Teach a consistent routine: sketch → identify tail/interval → find z → table lookup → probability → interpret.
  • Practice three core patterns: left of z, right of z, and between two z-values.
  • For percentiles, begin with the cumulative probability, locate z, then use x = μ + zσ.
  • Require learners to write the probability statement before the numerical answer.

Enrichment

  • Compare percentiles and raw scores from different normal distributions.
  • Use spreadsheet functions or graphing technology to verify Z-table results.
  • Investigate how changing μ and σ changes the raw cut-off corresponding to the same percentile.
  • Connect percentile problems to later normal-distribution applications and decision making.
