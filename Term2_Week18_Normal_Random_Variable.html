Weekly Learning Intentions

  • Describe the main characteristics of a normal distribution.
  • Relate the mean and standard deviation to the center and spread of a normal distribution.
  • Calculate z-scores for values from a normal random variable.
  • Convert between an original normal variable and the standard normal variable.
  • Interpret z-scores as positions relative to the mean and standard deviation.
Evidence-informed cycle: retrieve → notice patterns → explain evidence → explicitly model → guided practice → error analysis → independent application → mastery check → targeted response.

SESSION 1 — Illustrating the Normal Random Variable

Daily objectives: Identify and describe the key characteristics of a normal random variable.

ACTIVITY

Evidence gathering

Examine bell-shaped and skewed graphs. Learners identify center, symmetry, spread, and where observations cluster.

ANALYSIS

Formative check

Compare graphs and justify which characteristics support a normal model.

ABSTRACTION

Explicit modeling

Model that a normal distribution is continuous, bell-shaped, and symmetric; in an ideal normal distribution, mean = median = mode.

APPLICATION

Guided → independent

Describe several graphs and explain whether each is consistent with a normal model.

Evidence-to-action: If learners focus only on “bell-shaped,” compare normal and non-normal examples and revisit symmetry and center.

SESSION 2 — Calculating and Interpreting Z-Scores

Daily objectives: Calculate z-scores and explain positive, negative, and zero z-scores.

ACTIVITY

Evidence gathering

Compare raw scores from distributions with different means and standard deviations.

ANALYSIS

Formative check

Discuss why raw scores alone may not show relative position.

ABSTRACTION

Explicit modeling

Model z = (x − μ)/σ and interpret z = 0, positive z, and negative z.

APPLICATION

Guided → independent

Calculate and interpret z-scores in practical measurement and assessment contexts.

Evidence-to-action: If learners reverse the subtraction, use a number line and the phrase “value minus mean.”

SESSION 3 — Converting to and from the Standard Normal Variable

Daily objectives: Convert an original normal-variable value to z and recover x from a given z-score.

ACTIVITY

Evidence gathering

Match values to positions one or more standard deviations from the mean.

ANALYSIS

Formative check

Analyze errors in sign, substitution, and reverse conversion.

ABSTRACTION

Explicit modeling

Model z = (x − μ)/σ and x = μ + zσ.

APPLICATION

Guided → independent

Convert raw values to z-scores and z-scores back to original measurements.

Evidence-to-action: If learners use x = z − μ, derive x = μ + zσ from the z-score formula.

SESSION 4 — Integrated Normal-Variable Application

Daily objectives: Select the correct conversion, solve a multi-step problem, and interpret the result.

ACTIVITY

Evidence gathering

Sort prompts into “find z” and “find x,” identifying μ and σ.

ANALYSIS

Formative check

Compare solutions and locate errors involving sign or standard deviation.

ABSTRACTION

Explicit modeling

Use: identify x, μ, σ → choose direction → substitute → calculate → interpret.

APPLICATION

Guided → independent

Complete an integrated normal-variable problem independently and justify the interpretation.

Evidence-to-action: Use mastery evidence to distinguish conceptual, procedural, and interpretation errors.

LEARNER GUIDE

Normal Random Variable

Understand normal-distribution characteristics and standardization.

What You Will Learn

  • Recognize the characteristics of a normal distribution.
  • Understand mean and standard deviation as measures of center and spread.
  • Calculate z-scores.
  • Convert z-scores back to original values.
  • Interpret standardized positions.

Essential Definitions

TermMeaning
Normal random variableA continuous random variable modeled by a normal distribution.
Normal distributionA continuous, bell-shaped, symmetric probability distribution.
Mean (μ)The center of the distribution.
Standard deviation (σ)A measure of spread around the mean.
Standard normal variableA standardized normal variable with mean 0 and standard deviation 1.
z-scoreA standardized value showing how many standard deviations a value is from the mean.

Key Ideas and Formulas

  • The normal curve is symmetric and bell-shaped.
  • In an ideal normal distribution, mean = median = mode.
  • The standard normal distribution has μ = 0 and σ = 1.
z = (x − μ)/σ
x = μ + zσ

Worked Examples

Example 1

μ = 70, σ = 10, x = 85.

z = (85−70)/10 = 1.5

The value is 1.5 standard deviations above the mean.

Example 2

μ = 80, σ = 8, x = 68.

z = (68−80)/8 = −1.5

The value is 1.5 standard deviations below the mean.

Example 3

μ = 70, σ = 10, z = 1.5.

x = 70 + (1.5)(10) = 85

Common Mistakes

  • Using the wrong μ or σ.
  • Reversing x − μ.
  • Thinking a negative z means a negative raw value.
  • Forgetting to multiply z by σ in reverse conversion.
  • Interpreting z as a raw score.

Real-World Connections

Normal models can support analysis of measurements, assessment results, manufacturing quality, biological measurements, and other approximately bell-shaped data.

Activity Sheet — Complete Solutions

  1. Continuous, bell-shaped, and symmetric.
  2. Mean = median = mode.
  3. Mean = 0; standard deviation = 1.
  4. The value is exactly at the mean.
  5. z = (x − μ)/σ.
  6. The value is below the mean.
  7. z = (85−70)/10 = 1.5.
  8. z = (68−80)/8 = −1.5.
  9. z = (55−50)/5 = 1; one SD above the mean.
  10. x = 100 + (1.25)(20) = 125.
  11. x = 60 + (−2)(6) = 48.
  12. z = (72−75)/5 = −0.6; 0.6 SD below the mean.
  13. The arithmetic sign is wrong. Correct z = (70−80)/10 = −1.
  14. A z-score is standardized; it expresses position in SD units, not the original raw value.
  15. Symmetry means equal distances from the mean have corresponding positions on opposite sides.
  16. z = 2 means 2 SD above the mean.
  17. For z = −1.5: x = 250−30 = 220. For z = 2: x = 250+40 = 290.
  18. Answers vary; require realistic μ and σ, correct calculations, and interpretations.

Assessment — Complete Solutions

  1. A. bell-shaped and symmetric.
  2. C. equal.
  3. z = (85−70)/10 = 1.5.
  4. B. 2 standard deviations below the mean.
  5. x = 100 + (1.5)(20) = 130.
  6. Mean = 0; SD = 1.
  7. Use z = (x−μ)/σ: subtract the mean from the raw value and divide by the standard deviation.
  8. z = (91−75)/8 = 2. Thus 91 is 2 SD above the mean. For z = −1.25, x = 75 + (−1.25)(8) = 65, which is 1.25 SD below the mean.

TEACHER NOTES

Support, Remediation and Enrichment

Common Learner Misconceptions

  • Thinking every bell-shaped graph is normal.
  • Confusing mean and standard deviation.
  • Thinking a negative z means a negative raw value.
  • Reversing x − μ.
  • Forgetting z × σ in reverse conversion.
  • Interpreting z as a raw score.

Remediation

  • Use a labeled bell curve and number line.
  • Place values one, two, and three SDs from μ.
  • Use “value − mean, then divide by SD.”
  • Use “mean + z × SD” for reverse conversion.
  • Require verbal interpretation after computation.

Enrichment

  • Compare z-scores from different tests.
  • Use a spreadsheet to calculate and graph standardized values.
  • Explore how changing μ shifts a normal distribution and changing σ changes spread.
  • Connect standardization to later probability and percentile work.
