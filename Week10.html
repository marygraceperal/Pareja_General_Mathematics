SESSION 1 — Linear and Absolute Value Functions

Daily objective: Sketch and interpret linear and absolute value functions using equations, tables, and key points.

ACTIVITY

Elicit

Display a straight-line graph and a V-shaped graph. Ask learners what visual features distinguish them and what information a graph communicates.

ANALYSIS

Formative Check

Compare y = x and y = |x|. Identify slope, intercept, symmetry, and the effect of changing signs or constants.

ABSTRACTION

Explicit Modeling
Linear: y = mx + b
Absolute value: y = a|x − h| + k
Vertex: (h,k)

Model a table → plot key points → connect according to the function's shape.

APPLICATION

Guided → Independent

Sketch y = 2x − 1 and y = |x − 2| + 1. Learners identify the slope/intercept or vertex and describe the graph.

Evidence-to-action: If learners plot points but do not recognize the shape, use a small set of anchor points and ask them to verbalize the pattern before drawing.

SESSION 2 — Quadratic Functions

Daily objective: Sketch quadratic functions using a table and key features, including vertex and axis of symmetry.

ACTIVITY

Connect

Use a simple projectile or arch-shaped situation. Ask learners what makes the graph curve and where its highest or lowest point would occur.

ANALYSIS

Reasoning

Compare y = x², y = (x − 2)² + 1, and y = −x². Identify shifts, reflection, vertex, and opening direction.

ABSTRACTION

Explicit Modeling
y = ax² + bx + c
Vertex x-coordinate: x = −b/(2a)

Find the vertex, axis of symmetry, selected points, and intercepts when useful; then sketch the parabola.

APPLICATION

Practice

Sketch a quadratic model, identify its maximum/minimum, and explain what the key point means in context.

Teacher response: When symmetry is missed, fold/compare points equidistant from the axis or use a coordinate table that pairs equal distances.

SESSION 3 — Square Root and Cube Root Functions

Daily objective: Sketch square root and cube root functions and identify their key features from equations.

ACTIVITY

Retrieve

Recall perfect squares and cubes. Ask learners which x-values make √x and ∛x easy to plot.

ANALYSIS

Error Analysis

Examine graphs with incorrect starting points or orientations. Determine whether the error came from the table, transformation, or plotting.

ABSTRACTION

Explicit Modeling
y = √(x − h) + k
y = ∛(x − h) + k

For square root, begin with the endpoint/domain. For cube root, use symmetric values around the central point when convenient.

APPLICATION

Guided → Independent

Sketch y = √(x − 1) + 2 and y = ∛(x + 1) − 2. Identify starting/central points and describe the transformations.

Evidence-to-action: If learners confuse the two graph shapes, provide a visual comparison and require one sentence describing each function's characteristic shape.

SESSION 4 — Modeling and Solving Real-Life Problems

Daily objective: Select an appropriate function, construct or interpret its graph, solve a real-world problem, and justify the reasonableness of the result.

ACTIVITY

Retrieval

Function sort: match equations/graphs to linear, absolute value, quadratic, square root, or cube root models.

ANALYSIS

Reasoning

Compare two possible models for the same situation. Discuss which graph better represents the context and why.

ABSTRACTION

Synthesis

Use the routine: Understand context → Choose function → Define variables → Model → Graph → Solve → Interpret → Check.

APPLICATION

Mastery

Solve an integrated modeling task involving a cost relationship, distance from a reference point, or height/time relationship. Explain the meaning of the graph and answer.

Evidence-to-action: Use the final task to identify whether the learner needs support with function selection, graphing, algebraic solving, or interpretation.

LEARNER GUIDE

Functions and Their Graphs

A practical guide to recognizing, sketching, and applying common functions.

What You Will Learn

  • How to recognize linear, absolute value, quadratic, square root, and cube root functions.
  • How to sketch each graph using key points and features.
  • How transformations affect a graph.
  • How to use graphs to interpret and solve real-world problems.

Essential Definitions

FunctionKey graph idea
LinearStraight line; slope controls steepness/direction.
Absolute valueV-shaped graph; vertex is the turning point.
QuadraticParabola; vertex is a maximum or minimum depending on opening direction.
Square rootCurve with an endpoint and a restricted domain in its basic form.
Cube rootS-shaped curve passing through its central point in its basic form.

Key Forms

Linear: y = mx + b
Absolute value: y = a|x − h| + k
Quadratic: y = ax² + bx + c
Square root: y = a√(x − h) + k
Cube root: y = a∛(x − h) + k

Step-by-Step Worked Examples

1. Linear

Sketch y = 2x − 1. Use x = 0, 1, 2.

Points: (0,−1), (1,1), (2,3). Plot the points and draw a straight line. Slope = 2 and y-intercept = −1.

2. Absolute Value

Sketch y = |x − 2| + 1.

Vertex = (2,1). Points include (1,2) and (3,2). The graph is V-shaped and symmetric about x = 2.

3. Quadratic

Sketch y = x² − 4x + 3.

Vertex x = −(−4)/(2) = 2. y = 4−8+3 = −1, so vertex = (2,−1). Axis: x = 2. The graph opens upward because a = 1.

4. Square Root

Sketch y = √(x − 1) + 2.

Endpoint = (1,2). Using x = 2,5,10 gives y = 3,4,5. The graph begins at (1,2) and extends rightward.

5. Cube Root

Sketch y = ∛(x + 1) − 2.

Central point = (−1,−2). Using x = −9, −2, −1, 0, 7 gives y = −4, −3, −2, −1, 0. The graph has the characteristic cube-root S shape.

Common Mistakes & Pitfalls

  • Plotting points but joining them with the wrong function shape.
  • Confusing the vertex of an absolute value graph with the y-intercept.
  • Using −b/(2a) incorrectly for a quadratic.
  • Forgetting the restricted domain of a basic square-root function.
  • Ignoring horizontal/vertical shifts inside or outside a function.
  • Giving a graph without explaining what its important features mean.

Real-World Connections

Functions can model costs, distances, height, time, production, and other quantities. A graph helps reveal trends, turning points, thresholds, and relationships that may be difficult to see from an equation alone.

Quick Self-Check

  1. What is the slope of y = 3x + 2?
  2. What is the vertex of y = |x − 4| + 2?
  3. What is the vertex of y = x² − 6x + 5?
  4. What is the endpoint of y = √(x + 3) − 1?
  5. What is the central point of y = ∛(x − 2) + 4?

Activity Sheet — Complete Solutions

  1. Linear. It has the form y = mx + b.
  2. Absolute value. It contains |x + 2|.
  3. Quadratic. It contains x².
  4. Square root. It contains √(x − 4).
  5. Cube root. It contains ∛(x + 3).
  6. m = −2; y-intercept = 5.
  7. Vertex = (3,2). Example points: (2,3) and (4,3).
  8. x = −b/(2a) = 6/2 = 3. y = 9−18+5 = −4. Vertex = (3,−4); axis x = 3.
  9. Endpoint = (−4,−2). Examples: x = −3 gives y = −1; x = 0 gives y = 0.
  10. Central point = (2,1). Examples: x = 1 gives y = 0; x = 10 gives y = 3.
  11. For y = 2x + 1, slope = 2, y-intercept = 1. Points such as (0,1), (1,3), (−1,−1) form a straight line.
  12. y = −x² + 4x. x-coordinate of vertex = −4/(2·−1) = 2. y = −4+8 = 4. Vertex = (2,4), a maximum because the parabola opens downward.
  13. The sign inside the absolute value is reversed when identifying h. |x − 5| gives h = 5, so the correct vertex is (5,2).
  14. x = −b/(2a) = 8/2 = 4, not −4. y = 16−32+7 = −9. Correct vertex = (4,−9).
  15. For real outputs, the radicand must be nonnegative: x − 2 ≥ 0, so x ≥ 2.
  16. In C(x) = 50x + 100, 50 is the cost per kilometer and 100 is the fixed starting/base cost.
  17. For h(t) = −5t² + 20t + 1: t = −20/[2(−5)] = 2 seconds. h(2) = −20 + 40 + 1 = 21 units. The ball reaches maximum height at 2 seconds.
  18. Answers vary. Full credit requires a valid function type, meaningful real-life context, equation, two accurate graph features, and a clear interpretation.

TEACHER NOTES

Support, Remediation and Enrichment

Common Learner Misconceptions

  • Confusing function type from appearance alone without checking the equation.
  • Reading the sign inside a transformed function incorrectly.
  • Forgetting the factor 2a in the quadratic vertex formula.
  • Plotting points without respecting the characteristic graph shape.
  • Ignoring domain restrictions for square-root functions.
  • Solving the algebra correctly but failing to interpret the graph in context.

Remediation

  • Use a five-function identification chart.
  • Begin with parent functions before introducing transformations.
  • Require learners to mark vertex/endpoint/central point before plotting.
  • Use tables with deliberately chosen easy x-values.
  • Provide error-analysis cards based on actual learner mistakes.
  • For modeling, separate function selection from computation before combining them.

Enrichment

  • Use GeoGebra or another graphing tool to explore transformations.
  • Compare two possible models for the same real-world situation.
  • Create a mini “function museum” showing one real-life use for each function type.
  • Investigate how changing a, h, or k changes a graph.
