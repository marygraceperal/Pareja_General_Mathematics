SESSION 1 — Discrete and Continuous Random Variables

Daily objectives: Identify random variables and differentiate discrete and continuous variables using practical examples.

ACTIVITY

Classify

Sort examples such as number of siblings, number of customers, height, temperature, waiting time, and amount of water into “countable” and “measurable.”

ANALYSIS

Formative check

Discuss why a count can take separate values while a measurement can take values within an interval. Defend classifications.

ABSTRACTION

Explicit modeling

Define a random variable and model the distinction: discrete variables have countable possible values; continuous variables can take any value within an interval.

APPLICATION

Guided → independent

Learners classify new school, household, business, and community situations and explain the choice.

Evidence-to-action: If learners classify by “small/large” rather than count/measure, return to the question: “Can the possible values be counted one by one?”

SESSION 2 — Probability Distribution and Expected Value

Daily objectives: Construct a simple discrete probability distribution and calculate and interpret its expected value.

ACTIVITY

Connect

Use a simple game with possible scores. Learners list outcomes and discuss how frequently each outcome is expected to occur.

ANALYSIS

Reasoning

Check whether a proposed probability distribution is valid by verifying that probabilities are nonnegative and sum to 1.

ABSTRACTION

Explicit modeling

Model E(X) = ΣxP(x). Explain expected value as the long-run average outcome, not necessarily an outcome that must occur in one trial.

E(X) = Σ xP(x)

APPLICATION

Guided → independent

Learners calculate expected values from tables and explain the meaning in the given context.

Evidence-to-action: If learners add x-values without weighting by probability, require a two-column table showing x and xP(x).

SESSION 3 — Variance and Standard Deviation

Daily objectives: Calculate variance and standard deviation for a discrete random variable and interpret variability around the expected value.

ACTIVITY

Retrieve

Review expected value, then compare two simple distributions with similar means but different spreads.

ANALYSIS

Error analysis

Examine a solution that forgets to square deviations. Identify the error and explain why variance cannot be negative.

ABSTRACTION

Explicit modeling

Model Var(X) = Σ(x − μ)²P(x), followed by σ = √Var(X). Emphasize organized tables and correct substitution.

Var(X) = Σ(x − μ)²P(x)    σ = √Var(X)

APPLICATION

Guided → independent

Learners calculate variance and standard deviation and describe which distribution is more variable.

Evidence-to-action: If learners use x − μ without squaring, use a deviation table and ask what happens when positive and negative deviations are combined.

SESSION 4 — Integrated Interpretation and Mastery

Daily objectives: Solve and interpret a complete discrete-random-variable problem involving expected value, variance, and standard deviation.

ACTIVITY

Retrieve

Quick classification: discrete/continuous, then identify the correct measure needed for a given question.

ANALYSIS

Strategy comparison

Compare two complete solutions and locate mistakes involving probabilities, expected value, variance, or interpretation.

ABSTRACTION

Synthesis

Use the routine: define X → list values → check probabilities → calculate μ → calculate variance → calculate σ → interpret.

APPLICATION

Mastery

Complete an integrated real-world problem independently and justify the meaning of each statistic.

Evidence-to-action: Use the mastery evidence to separate conceptual classification errors from computational and interpretation errors.

LEARNER GUIDE

Random Variables

Understand how chance-based quantities are represented and measured.

What You Will Learn

  • Distinguish discrete and continuous random variables.
  • Read a discrete probability distribution.
  • Calculate expected value.
  • Calculate variance and standard deviation.
  • Interpret the results in context.

Essential Definitions

TermMeaning
Random variableA variable whose numerical value is determined by the outcome of a random process.
Discrete random variableA random variable with countable possible values.
Continuous random variableA random variable that can take values across an interval of measurements.
Probability distributionA listing of possible values of a discrete random variable and their probabilities.
Expected valueThe probability-weighted average of the possible values of a discrete random variable.
VarianceA measure of the weighted squared deviation of values from the expected value.
Standard deviationThe positive square root of the variance.

Key Ideas and Formulas

For a valid discrete distribution: P(x) ≥ 0 and ΣP(x) = 1
Expected value: μ = E(X) = ΣxP(x)
Variance: Var(X) = Σ(x − μ)²P(x)
Standard deviation: σ = √Var(X)

Expected value describes the long-run average. Standard deviation describes the typical spread of values around the expected value.

Worked Examples

Example 1 — Classifying variables

Number of customers entering a store is discrete because customers can be counted. The waiting time of a customer is continuous because time can be measured to increasingly precise values.

Example 2 — Expected value

Suppose X has values 0, 1, 2 with probabilities 0.2, 0.5, 0.3.

E(X) = 0(0.2) + 1(0.5) + 2(0.3) = 1.1

Example 3 — Variance and standard deviation

Using μ = 1.1:

Var(X) = (0−1.1)²(0.2) + (1−1.1)²(0.5) + (2−1.1)²(0.3) = 0.49
σ = √0.49 = 0.70

Example 4 — Interpretation

An expected value of 1.1 means that over many repetitions, the average outcome approaches 1.1. A standard deviation of 0.70 indicates the outcomes have a moderate spread around that average.

Common Mistakes

  • Calling every random variable discrete because it has numerical values.
  • Forgetting that probabilities in a discrete distribution must total 1.
  • Calculating expected value as a simple average without probabilities.
  • Forgetting to square deviations in variance.
  • Reporting variance as the same unit as the original variable without checking context.
  • Interpreting expected value as a value that must occur in one trial.

Real-World Connections

Random variables are used in customer counts, production defects, insurance claims, waiting times, measurements, game outcomes, business planning, and scientific investigations.

TEACHER NOTES

Support, Remediation and Enrichment

Common Learner Misconceptions

  • Thinking every numerical variable is discrete.
  • Confusing a count with a measurement.
  • Forgetting that probabilities must total 1.
  • Using an ordinary mean instead of a probability-weighted mean.
  • Forgetting to square deviations in variance.
  • Interpreting expected value as a guaranteed single-trial result.

Remediation

  • Use sorting cards labeled COUNT and MEASURE.
  • Have learners build probability tables with a final probability-sum check.
  • Use an xP(x) column for expected value.
  • Use an organized deviation table for variance.
  • Ask learners to verbalize the meaning of μ and σ after every computation.

Enrichment

  • Model customer arrivals, product defects, or game outcomes using a discrete distribution.
  • Compare two distributions with similar means but different standard deviations.
  • Use a spreadsheet to calculate expected value, variance, and standard deviation and verify manual work.
  • Ask learners to explain how a business could use expected value in planning.
