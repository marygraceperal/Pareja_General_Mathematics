  • Describe patterns by inspection, including patterns in art and nature.
  • Determine the next term of a given pattern, including the Fibonacci sequence.
  • Identify the rule of a given pattern.
  • Illustrate the attributes of arithmetic and geometric sequences.
  • Solve problems involving arithmetic and geometric sequences.

Learning Intentions

Learners will recognize, describe, represent and explain patterns; determine missing or next terms; infer rules; distinguish arithmetic from geometric sequences; and solve contextual problems involving both types of sequences.

Observable Objectives

  • Describe visible numerical and visual patterns using precise mathematical language.
  • Determine missing or next terms, including terms in Fibonacci sequences, and justify the pattern.
  • Identify and represent the rule of a sequence and classify it as arithmetic or geometric when appropriate.
  • Apply arithmetic and geometric sequence formulas to solve and interpret real-world problems.

SESSION 1 — Describing Patterns and Finding Next Terms

Daily objective: By the end of the session, learners will describe numerical and visual patterns and determine the next term using evidence from the observed relationship.

A1 • ACTIVITY

Retrieval + Notice

Show short patterns such as 2, 4, 6, 8, …; 3, 6, 12, 24, …; and a simple visual growth pattern. Learners write what changes and predict the next term.

Evidence: prediction + one-sentence description.

A2 • ANALYSIS

Formative Check

Pairs compare predictions and answer: “What stayed the same? What changed? What operation connects one term to the next?” Teacher addresses guessing without justification.

Evidence: identified relationship.

A3 • ABSTRACTION

Explicit Modeling

Teacher models how to inspect consecutive terms, test addition/subtraction/multiplication/division relationships, and describe a pattern precisely.

A sequence is an ordered list of numbers or objects that follows an identifiable pattern or rule.

A4 • APPLICATION

Guided → Independent

Learners solve five new sequences, determine the next term and write the rule in words. One item uses a visual pattern from nature or art.

Exit evidence: accurate next term + justified rule.

Ways Forward: If learners can predict but cannot explain, use “term-to-term” sentence frames. If they explain accurately, ask them to create a pattern with a hidden rule.

SESSION 2 — Fibonacci Sequence and Rules of Patterns

Daily objective: By the end of the session, learners will determine Fibonacci terms and infer the rule of given patterns using organized evidence.

A1 • ACTIVITY

Retrieval + Exploration

Complete partial sequences: 1, 1, 2, 3, 5, …; 2, 3, 5, 8, 13, …; and non-Fibonacci patterns. Learners predict missing terms.

A2 • ANALYSIS

Error Analysis

Examine a learner's incorrect claim that Fibonacci terms are found by adding 2 each time. Learners identify the error and explain the actual relationship.

Evidence: correction with justification.

A3 • ABSTRACTION

Explicit Modeling

Model the Fibonacci relationship: after the first two terms, each term is the sum of the two preceding terms.

Fₙ = Fₙ₋₁ + Fₙ₋₂

For general pattern rules, compare consecutive terms and test whether the same operation continues to work.

A4 • APPLICATION

Collaborative → Independent

Teams analyze four sequences and state each rule. Each learner independently solves a Fibonacci item and one non-Fibonacci rule item.

Ways Forward: Learners needing support use a two-column “previous two terms → sum” table. Learners ready for enrichment create a sequence whose rule is not obvious from only two terms and explain why more evidence is needed.

SESSION 3 — Arithmetic and Geometric Sequences

Daily objective: By the end of the session, learners will identify and illustrate the attributes of arithmetic and geometric sequences and determine missing terms using the appropriate relationship.

A1 • ACTIVITY

Compare

Compare pairs: 5, 8, 11, 14, … and 3, 6, 12, 24, …. Learners calculate consecutive differences and ratios.

A2 • ANALYSIS

Formative Check

Learners decide whether each sequence has a constant difference, a constant ratio, or neither. Discuss why “multiply by 3” is not an arithmetic rule and why “add 3” is not geometric.

A3 • ABSTRACTION

Explicit Modeling

Teacher introduces the common difference d and common ratio r.

Arithmetic: aₙ = a₁ + (n − 1)d
Geometric: aₙ = a₁rⁿ⁻¹

Attributes: arithmetic → constant difference; geometric → constant non-zero ratio.

A4 • APPLICATION

Guided → Independent

Learners classify sequences, find d or r, determine a requested term, and explain which model they selected.

Evidence: classification + correct model + computation.

Ways Forward: Use a “difference or ratio?” checklist for learners who confuse the two. Extend proficient learners to reverse problems involving an unknown first term, difference or ratio.

SESSION 4 — Solving Problems with Arithmetic and Geometric Sequences

Daily objective: By the end of the session, learners will select an appropriate arithmetic or geometric sequence model, solve a contextual problem, verify the result and interpret its meaning.

A1 • ACTIVITY

Retrieval

Four quick prompts: identify d, identify r, select arithmetic/geometric, and write the corresponding nth-term formula.

A2 • ANALYSIS

Model Selection

Analyze two contextual problems and discuss what evidence tells us whether a constant amount or constant factor is changing.

A3 • ABSTRACTION

Synthesis

Build a decision flow:

List terms → compare differences/ratios → classify → identify known values → select formula → substitute → calculate → interpret/check

A4 • APPLICATION

Mastery Task

Individually solve an arithmetic and a geometric contextual problem. Learners show formula, substitution, answer and interpretation. Calculator/spreadsheet may be used to verify.

Ways Forward: Classify learners as Not Yet Mastered, Developing or Mastered. Remediate model selection before repeating calculations. Provide transfer problems to learners demonstrating mastery.

LEARNER GUIDE

Patterns and Sequences

Discussion and study guide for four sessions.

What You Will Learn

  • Describe patterns in numbers, art and nature.
  • Find the next or missing term of a sequence.
  • Recognize and use the Fibonacci sequence.
  • Identify a sequence's rule.
  • Distinguish arithmetic from geometric sequences.
  • Find a specified term and solve contextual problems.

Essential Definitions

TermMeaning
PatternAn identifiable regularity or relationship in a set of numbers, objects or events.
SequenceAn ordered list of terms following a pattern or rule.
TermAn individual member of a sequence, often represented by aₙ.
Arithmetic sequenceA sequence in which the difference between consecutive terms is constant.
Common differenceThe constant value added to each term to obtain the next term of an arithmetic sequence.
Geometric sequenceA sequence in which the ratio of consecutive terms is constant.
Common ratioThe constant factor by which each term is multiplied to obtain the next term of a geometric sequence.
Fibonacci sequenceA sequence in which, after the first two terms, each term is the sum of the two preceding terms.

Key Ideas and Formulas

Arithmetic: aₙ = a₁ + (n − 1)d
Geometric: aₙ = a₁rⁿ⁻¹
Arithmetic common difference: d = aₙ − aₙ₋₁
Geometric common ratio: r = aₙ ÷ aₙ₋₁, when the preceding term is non-zero
Fibonacci: Fₙ = Fₙ₋₁ + Fₙ₋₂
Decision tip: Check differences first. If they are constant, the sequence is arithmetic. If differences are not constant, check ratios. A constant ratio indicates a geometric sequence.

Worked Examples

Example 1 — Describe and Extend a Pattern

Sequence: 7, 10, 13, 16, …

Each term increases by 3. The next term is 16 + 3 = 19.

Example 2 — Fibonacci

Sequence: 2, 3, 5, 8, 13, …

Each new term is the sum of the previous two: 5 + 8 = 13, then 8 + 13 = 21.

Example 3 — Arithmetic nth Term

Find the 12th term of 5, 9, 13, 17, …

a₁ = 5, d = 4, n = 12.
a₁₂ = 5 + (12 − 1)(4) = 5 + 44 = 49.

Example 4 — Geometric nth Term

Find the 6th term of 3, 6, 12, 24, …

a₁ = 3, r = 2, n = 6.
a₆ = 3(2⁵) = 3 × 32 = 96.

Example 5 — Contextual Arithmetic Problem

A student saves ₱500 in the first month and increases the amount saved by ₱100 every month. How much is saved in the 8th month?

a₁ = ₱500, d = ₱100, n = 8.
a₈ = ₱500 + 7(₱100) = ₱1,200.

Common Mistakes and Pitfalls

  1. Guessing a next term without stating the relationship.
  2. Confusing constant difference with constant ratio.
  3. Using the arithmetic formula for a geometric sequence or vice versa.
  4. Forgetting that n − 1 is the exponent in the geometric nth-term formula.
  5. Substituting the wrong first term.
  6. Failing to check whether the final answer fits the context.

Real-World Connections

Patterns and sequences help describe repeated changes in savings, production, population models, repeated designs, natural arrangements and other situations where quantities change according to a recognizable rule.

Quick Self-Check

  1. What makes a sequence arithmetic?
  2. What makes a sequence geometric?
  3. How is a Fibonacci term generated?
  4. What should you check before choosing an nth-term formula?
  5. Why should a solution include an interpretation or reasonableness check?

Activity Sheet — Complete Solutions

  1. 4, 7, 10, 13: add 3. Next term = 16.
  2. 2, 4, 8, 16: multiply by 2. Next term = 32.
  3. Each term after the first two is the sum of the preceding two: 5 + 3 = 8; 3 + 5 = 8 depending on sequence position; specifically sequence 1,1,2,3,5 gives 8, 13.
  4. d = 14 − 18 = −4.
  5. r = 15 ÷ 5 = 3.
  6. Arithmetic; consecutive differences are 4.
  7. a₁ = 6, d = 4, n = 15. a₁₅ = 6 + 14(4) = 6 + 56 = 62.
  8. a₁ = 2, r = 3, n = 8. a₈ = 2(3⁷) = 2(2,187) = 4,374.
  9. Rule: subtract 5 each time. a₁₀ = 30 + 9(−5) = −15.
  10. a₁ = ₱300, d = ₱50, n = 10. a₁₀ = ₱300 + 9(₱50) = ₱750.
  11. a₁ = 400, r = 2, n = 6. a₆ = 400(2⁵) = 400 × 32 = 12,800 units.
  12. a₁ = 12, d = 4, n = 18. a₁₈ = 12 + 17(4) = 80 seats.
  13. No. It is arithmetic because the constant difference is 4. Ratios are not constant.
  14. The error is using an arithmetic formula for a geometric sequence. Here r = 2. a₁₀ = 3(2⁹) = 3 × 512 = 1,536.
  15. Sequence A is arithmetic because the difference is −10. Sequence B is geometric because each term is multiplied by 0.9.
  16. Let 7, x, 19 be consecutive terms. Arithmetic means equal differences: x − 7 = 19 − x. Thus 2x = 26 and x = 13. Sequence: 7, 13, 19, 25, 31.
  17. 1,215 = 5(3ⁿ⁻¹). Divide by 5: 243 = 3ⁿ⁻¹ = 3⁵. Therefore n − 1 = 5 and n = 6. It is the 6th term.
  18. Arithmetic example: 4, 8, 12, 16, 20, 24 (d = 4). Geometric example: 4, 8, 16, 32, 64, 128 (r = 2). Both begin 4, 8, but one adds 4 while the other multiplies by 2.

TEACHER NOTES

Instructional Support and Ways Forward

Use learner evidence to decide the next instructional move.

Common Misconceptions

  • Assuming every sequence has a unique rule from only two or three terms.
  • Confusing “increasing” with “geometric.”
  • Using difference when the pattern is multiplicative.
  • Using the wrong nth-term formula.
  • Forgetting n − 1 in the formulas.
  • Giving a next term without evidence for the rule.

Remediation Strategies

  • Use concrete objects before symbolic sequences.
  • Have learners write consecutive differences beneath terms.
  • If needed, write consecutive ratios beside terms.
  • Use paired examples: arithmetic vs geometric.
  • Provide formula frames with known values highlighted.
  • Reassess the exact failed step.

Enrichment and Transfer

  • Ask learners to photograph or sketch a pattern in art or nature and describe its mathematical regularity.
  • Create a sequence with a specified nth term.
  • Work backward to find a missing first term, common difference or ratio.
  • Use a spreadsheet to generate the first 15 terms of an arithmetic or geometric sequence.
  • Compare two models and explain which better represents a real situation.
