SESSION 1 — Understanding Piecewise Functions

Daily objective: Explain why different rules can apply to different intervals and identify the rule and condition represented by each piece.

ACTIVITY

Elicit

Present a transport fare that charges a base amount for the first distance and a different rate after a threshold. Learners predict whether one rule can describe the whole fare.

ANALYSIS

Formative Check

Compare situations with one rule and multiple rules. Ask: Where does the rule change? What condition tells us which rule to use?

ABSTRACTION

Explicit Modeling
A piecewise function uses different rules on specified intervals.
f(x) = rule 1, condition 1; rule 2, condition 2; …

Model how the context becomes a table of intervals, rules, and conditions.

APPLICATION

Guided → Independent

Given a simple fare schedule, learners identify which rule applies for several distances and explain why.

Teacher response: If learners choose a rule without checking the condition, use color-free interval cards and require them to state the condition before calculating.

SESSION 2 — Representing Piecewise Functions

Daily objective: Construct a piecewise function from a practical situation and represent its intervals and conditions correctly.

ACTIVITY

Connect

Examine a purchasing scheme with a lower unit price after a quantity threshold. Learners organize the information into intervals.

ANALYSIS

Reasoning

Determine whether boundary values belong to the first or second rule. Discuss the meaning of ≤, <, ≥, and > in context.

ABSTRACTION

Explicit Modeling

Model the sequence: define x → identify intervals → write each rule → assign conditions → check boundary coverage → test sample inputs.

APPLICATION

Guided → Independent

Create a piecewise purchasing function from a provided price schedule and evaluate it for selected quantities.

Evidence-to-action: If boundary errors appear, have learners substitute the boundary into both rules and explain which condition accepts it.

SESSION 3 — Evaluating and Solving Piecewise Problems

Daily objective: Evaluate piecewise functions and solve practical problems by selecting the correct rule and interpreting the result.

ACTIVITY

Retrieve

Quick retrieval: identify the applicable interval for five input values from a displayed piecewise rule.

ANALYSIS

Error Analysis

Inspect an incorrect solution in which the learner used the first rule for every input. Identify exactly where the reasoning failed.

ABSTRACTION

Explicit Modeling
Evaluate: 1. Locate x in an interval. 2. Select its rule. 3. Substitute x. 4. Compute. 5. Interpret in context.

APPLICATION

Practice

Solve fare and purchasing tasks, showing the interval decision before the numerical calculation.

Teacher response: If computation is correct but rule selection is wrong, reteach interval reading rather than repeating arithmetic drills.

SESSION 4 — Income Tax and Real-World Modeling

Daily objective: Model and solve an income-tax-style piecewise problem, justify the selected rule, and explain the reasonableness of the answer.

ACTIVITY

Connect

Discuss why a progressive system may apply different rules to different income brackets. Focus on the mathematical structure rather than memorizing tax policy.

ANALYSIS

Formative Check

Given several income values, learners identify the bracket and explain why the boundary matters.

ABSTRACTION

Synthesis

Use the routine: Define variable → identify interval → choose rule → calculate → check boundary → interpret.

APPLICATION

Mastery

Solve an integrated piecewise scenario involving fare, purchasing, or an illustrative income-tax schedule. Explain the result in words.

Evidence-to-action: Use the final task to classify errors as context interpretation, interval selection, substitution, computation, or explanation.

LEARNER GUIDE

Piecewise Functions

Understanding functions that use different rules for different conditions.

What You Will Learn

  • What a piecewise function represents.
  • How to read intervals and conditions.
  • How to construct and evaluate a piecewise function.
  • How piecewise functions model fares, purchasing, and income-tax-style situations.

Essential Definitions

TermMeaning
Piecewise functionA function defined by different rules on different intervals of the domain.
PieceOne rule of the function together with the condition where it applies.
IntervalA set or range of input values for which a particular rule is used.
BoundaryA value where one rule ends or another begins.
DomainThe allowable input values of the function.

Key Representation

f(x) = { rule 1, when condition 1; rule 2, when condition 2; … }

The conditions should tell you exactly when each rule is used. For adjacent intervals, check boundary symbols carefully so that each relevant input is assigned appropriately.

Worked Examples

1. Simple evaluation

Suppose f(x) = 2x + 5 for x < 10, and f(x) = 3x + 1 for x ≥ 10. Find f(7) and f(10).

For x = 7, 7 < 10, so use 2x + 5: f(7) = 2(7) + 5 = 19.
For x = 10, 10 ≥ 10, so use 3x + 1: f(10) = 3(10) + 1 = 31.

2. Fare model

A fare is ₱50 for up to 4 km and ₱50 + ₱12 for every kilometer beyond 4 km. Model the fare for x > 4.

For 0 ≤ x ≤ 4, F(x) = 50. For x > 4, F(x) = 50 + 12(x − 4). At x = 6: F(6) = 50 + 12(2) = ₱74.

3. Purchasing

A product costs ₱40 each for the first 5 items and ₱35 each for each item after 5. For 8 items, the total is 5(40) + 3(35) = ₱305.

4. Illustrative tax structure

If an illustrative schedule states that income up to ₱100,000 is taxed at 5%, and income above ₱100,000 is taxed as ₱5,000 plus 10% of the amount above ₱100,000, then an income of ₱130,000 gives ₱5,000 + 0.10(₱30,000) = ₱8,000. This is a mathematical illustration, not current tax advice.

Common Mistakes & Pitfalls

  • Choosing a rule before checking the input interval.
  • Misreading ≤, <, ≥, and > at a boundary.
  • Using a later rule for an input that belongs to an earlier interval.
  • Forgetting fixed/base charges in a practical model.
  • Giving a numerical answer without interpreting it in context.

Real-World Connections

Piecewise functions naturally represent pricing tiers, transportation fares, utility charges, tax brackets, shipping fees, overtime arrangements, and other systems where the rule changes after a threshold.

Quick Self-Check

  1. Why can one situation require more than one rule?
  2. For f(x) = x + 2 when x < 5 and 2x when x ≥ 5, which rule is used at x = 5?
  3. What must you check before substituting an input into a piecewise function?
  4. Why are boundary symbols important?
  5. Give one practical situation that can be modeled piecewise.

TEACHER NOTES

Support, Remediation and Enrichment

Common Learner Misconceptions

  • Thinking every function must have one rule for the entire domain.
  • Ignoring the condition attached to each piece.
  • Misreading inequality symbols at boundaries.
  • Using the correct formula but an incorrect interval.
  • Confusing a base/fixed charge with a per-unit rate.
  • Solving numerically without interpreting the practical meaning.

Remediation

  • Start with concrete schedules before symbolic notation.
  • Use an interval → rule → substitute → answer routine.
  • Give boundary-focused examples such as x = 4, x = 5, and x = 10.
  • Use error-analysis tasks before additional computation practice.
  • Ask learners to underline the condition before selecting a rule.

Enrichment

  • Design a tiered school-store pricing system.
  • Model a transport fare with three distance brackets.
  • Compare two pricing systems and determine where one becomes more economical.
  • Represent a piecewise situation with a table and graph using appropriate technology.
